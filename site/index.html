  • never sends on its own
  • handles mixed languages like Taglish

05 / images

Images both ways

Send Claude a screenshot from your camera roll. See the charts and screenshots it made or read, right in the pane.

  • uploads are resized on the phone first
  • images from the session, one tap away
  • works on remote machines too
06 / machines

Every machine you herd

Orca reads your herdr machine list and reaches each one through an SSH tunnel. Nothing to install there beyond herdr.

  • local and SSH machines in one list
  • reconnects with backoff when a box sleeps
  • uploads and images work over SSH

setup · about five minutes
step 1

Run the bridge next to herdr

$ git clone https://github.com/kylledoestech/orca
$ cd orca/web && npm install && npm run build
$ cd ../bridge && npm install
$ npm start      # Node 22.18+, listens on 127.0.0.1:4280
step 2

Put it on your tailnet

$ tailscale serve --bg --https=443 http://127.0.0.1:4280
# https://<machine>.<tailnet>.ts.net
step 3

Open it on your phone

Open the address, choose “Add to home screen”, then turn on notifications from the bell.

faq
Is Orca part of herdr?
No. Orca is a separate client that talks to herdr’s socket API.
Do my remote machines need anything new?
Only herdr and SSH access. Orca opens a tunnel to each machine’s herdr socket.
Does anything leave my network?
Push notifications go through your browser’s push service. Voice clips go to Groq, and only when you use voice. Nothing else.
Who can open it?
Devices on your tailnet. The bridge listens only on localhost and rejects other origins.
Which phones work?
Built and tested on Android Chrome. iPhone is untested so far.
